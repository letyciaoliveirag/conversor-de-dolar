# Conversor de Dólar

Um conversor simples que transforma valores de reais (R$) em dólares (US$).

Criei o design e desenvolvi este projeto com HTML, CSS e JavaScript, com o objetivo de aprender ainda mais sobre essas tecnologias.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

1. Digite o valor em reais no campo.
2. Clique em **Converter** para ver o valor em dólares.
3. Clique em **Limpar** sempre que quiser fazer uma nova conversão.

## Observação

A cotação do dólar é fixa. Futuramente pretendo atualizar o projeto para buscar a cotação em tempo real, acompanhando as altas e quedas do dólar.
